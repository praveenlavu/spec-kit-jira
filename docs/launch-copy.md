## Repository description

Your AI agent does the Jira grunt work; you press yes. `skj` is a Spec Kit extension and a standard-library Python command line
tool that takes a Jira Cloud story to a pull request, with every write shown as a preview first. A community project, tested live
on a real Jira Cloud team-managed project.

## Catalog blurb

Take a Jira Cloud story to a pull request with your AI agent, step by step. `skj` previews every subtask, comment, pull
request and close, and writes nothing until you say yes. A checklist ties each acceptance criterion to its test, and a check
before merge reports any gap. Python standard library only. Team-managed projects; early version, tested live on a real Jira Cloud site.

## Announcement

Your AI agent can do the Jira grunt work now, and you still press yes.
`skj` takes a Jira Cloud story through Spec Kit: spec, plan, subtasks, tests, pull request.
Every write to Jira is a preview first, and the story closes only after the merge and your yes.
Each acceptance criterion is tied to the test that proves it; the gap report comes before merge.
It is an early, community version (team-managed projects, standard library Python): try it and tell us what breaks.
